# Capturas

Coloca aquí las capturas para el entregable (formato PNG):

| Archivo sugerido | Contenido |
|---|---|
| `circuito_wokwi.png` | Circuito completo en Wokwi (simulación detenida, se ve todo el cableado). |
| `simulacion_auto.png` | Simulación corriendo en modo AUTO: OLED con datos y LEDs encendidos. |
| `simulacion_critico.png` | Condición crítica (DHT22 > 38 °C): OLED con `!!! CRITICO !!!`. |
| `serial_monitor.png` | Monitor serie de Wokwi con los mensajes `[EVENTO]`, `[TELEMETRIA]` y `[CMD]`. |
| `dashboard_adafruit.png` | Dashboard de Adafruit IO con gauges, gráfico y controles. |
| `backend_log.png` | Terminal del backend recibiendo telemetría, comandos y ACKs. |
| `historico_cli.png` | Salida de `python -m backend.historico ...`. |

También va aquí el **zip del proyecto descargado desde Wokwi** (ver README principal).
